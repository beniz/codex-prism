# codex-prism 1.8.0-dev

Development prerelease of Git collaboration and manuscript review, built from
`feat_init_git_collab`. **1.7.1 remains the recommended stable release.**
Install this version explicitly to test the new collaboration workflow; normal
stable-release update notifications do not offer this prerelease.

## Git collaboration

- Connect an existing project or open a shared GitHub/Gitea repository using a
  repository URL or branch link, with contributor identity retrieved through the
  hosting API and editable before connecting.
- Support HTTPS credentials and existing SSH configuration. Credentials can be
  remembered in the system credential store when available.
- Synchronize connected projects after explicit Save or Keep. Autosave remains
  local. Opening or focusing a project also checks for updates.
- Resolve incoming conflicts in an isolated agent proposal and inspect the
  resulting diffs before accepting changes.
- Open connection settings from the Collaboration heading. The sidebar shows
  the connected repository, branch, status, and available reviews. The sync icon
  turns blue while working; synchronization appears below chat without moving
  sidebar rows.

## Manuscript reviewer

- Request a review with a larger, growing instruction field. The reviewer works
  in an isolated local workspace and branch, and its chat has a purple marker.
- Open findings directly from the sidebar in readable tabs beside the PDF, with
  Markdown formatting, source references, tables, and equations.
- Save findings independently of document edits. Keep selected tracked document
  files, defer suggestions for later, or discard suggestions while retaining the
  report locally. Saved reviews participate in normal repository synchronization.
- Continue editing after saving a review, then integrate retained suggestions
  through the existing conflict-aware acceptance workflow.

## Testing scope

These collaboration features are experimental. Test with a disposable copy of
an existing manuscript and a dedicated remote repository. Review branches remain
local; Git hosting, invitations, and repository permissions are managed on GitHub
or Gitea. Shared-branch push permissions are required, and rejected pushes remain
local. Submodules, Git LFS-managed inputs, and source symlinks are not supported
by this initial collaboration workflow.

Installing this prerelease uses the same application identity and settings as the
stable version; it is not a separate side-by-side application edition.

See [the collaboration guide](https://github.com/beniz/codex-prism/blob/v1.8.0-dev/docs/collaboration.md)
for connection, review, and synchronization details.

## Packages and installation

- **Ubuntu 26.04 x86_64:** `codex-prism-1.8.0-dev-linux-x86_64.deb` or
  `codex-prism-1.8.0-dev-x86_64.AppImage`. Older Linux distributions are not
  guaranteed to work. Install and authenticate Codex separately, and install
  TeX Live for compilation.
- **Windows 10/11 x64:** `codex-prism-1.8.0-dev-windows-x86_64-setup.exe`.
  Setup reuses existing prerequisites and can install missing Codex, MiKTeX,
  and WebView2. The installer is unsigned.
- **macOS Apple Silicon:** `codex-prism-1.8.0-dev-macos-arm64.dmg`. Copy the app
  into Applications; install/authenticate Codex and install MacTeX separately.
  The app is ad-hoc signed, not Apple-notarized. A blocked first launch can be
  approved through System Settings → Privacy & Security → Open Anyway.

Packages are installed manually. Python environments and scientific skills are
optional, and no Node.js or Rust installation is required to run the packaged
app. Existing PDFs can be viewed without a TeX compiler. Optimized PDF export
requires Ghostscript.

Verify downloads with `SHA256SUMS`. `release.json` records the source commit and
artifact hashes. Subsequent development builds will use new versioned tags;
published artifacts will not be replaced.
