# codex-prism 1.6.6

Desktop packages for **Ubuntu 26.04 LTS x86_64**, **Windows 10/11 x64**, and **macOS Apple Silicon**, built from the same v1.6.6 source tag.

## Changes

- Double-click LaTeX text to navigate to its position in the displayed PDF while retaining word selection and editor focus. Navigation falls back to the nearest mapped line in the same file; stale or ambiguous source matches are rejected. The destination is briefly highlighted without changing zoom or triggering compilation.
- Click the project title to open Project settings, with project renaming and a shared prompt. Shared instructions are stored locally in Prism and applied to each new turn across all project chats; saving them does not interrupt running turns.
- Remember the latest model and reasoning effort separately for each project.
- Recall previous prompts with Up in an empty composer. Down moves forward through history and returns to an empty draft; editing a recalled prompt restores normal arrow-key behavior.
- Improve Windows Codex discovery in standard WinGet user/machine locations, including native package executables when PATH aliases are missing. An already-installed response from WinGet triggers another discovery check; upgrades remain disabled. Custom installations may still require PATH configuration.

## Windows installation

Run `codex-prism-1.6.6-windows-x86_64-setup.exe`, then open the app and use **Connection → Sign in**.

Setup reuses existing tools and installs missing Codex and MiKTeX through WinGet, plus WebView2 when needed. Internet access and Windows App Installer (WinGet) are required for those downloads. A newly installed MiKTeX is configured to download missing packages; existing distribution settings are preserved. Ghostscript's optional setup wizard enables optimized PDF export and may request administrator approval. Silent setup skips this optional wizard.

The Windows installer is unsigned. Prerequisites are separate installations and remain installed when codex-prism is removed.

## Ubuntu installation

Install `codex-prism-1.6.6-linux-x86_64.deb`:

```sh
sudo apt install ./codex-prism-1.6.6-linux-x86_64.deb
```

Or make the AppImage executable and run it:

```sh
chmod +x codex-prism-1.6.6-x86_64.AppImage
./codex-prism-1.6.6-x86_64.AppImage
```

These packages target Ubuntu 26.04; older distributions are not guaranteed to work. Install/authenticate Codex separately, and install TeX Live for compilation:

```sh
sudo apt install texlive-latex-extra texlive-publishers texlive-fonts-recommended texlive-xetex texlive-luatex texlive-bibtex-extra biber
```

## macOS installation

Open `codex-prism-1.6.6-macos-arm64.dmg` and copy codex-prism into Applications. Install/authenticate Codex separately and install MacTeX, for example:

```sh
brew install --cask mactex-no-gui
```

The app detects Codex bundled with ChatGPT or uses your configured executable. The macOS app is ad-hoc signed, **not Apple-notarized**. After a blocked initial launch, use **System Settings → Privacy & Security → Open Anyway** to approve it.

## Requirements and verification

Existing PDFs can be viewed without a LaTeX compiler. Python environments and scientific skills are optional. Node.js and Rust are not required to run the packaged application.

Optimized PDF export additionally requires Ghostscript (`sudo apt install ghostscript` on Ubuntu or `brew install ghostscript` on macOS). Verify downloads against `SHA256SUMS`; `release.json` records the source commit and package hashes. Automatic application updates are not enabled.
