# codex-prism 1.7.1

Faster project browsing, more responsive parallel chats, and clearer progress while writing.

Desktop packages for Ubuntu 26.04 LTS x86_64, Windows 10/11 x64, and macOS Apple Silicon, built from the same v1.7.1 source tag.

## Faster projects and conversations

- Cache project PDF thumbnails across restarts and reuse rendering workers while browsing.
- Show the workspace before project loading completes; prioritize document sources and existing PDFs, defer ancillary files and images, and restore the active conversation first.
- Retain the three most recently viewed chat histories, including long conversations. Switch directly to the latest messages without animated scrolling or replaying the history from the beginning.
- Prepare uncached history progressively with a consistent loading message. Defer tab-selection persistence and reduce redraws while typing.
- Report document, conversation, agent, proposal and PDF activity below the composer.

## Parallel PDF work and navigation

- Build completed chats' PDFs in the background with up to three concurrent compilations, and reuse saved builds when switching tabs.
- Render chat PDFs through two workers with foreground priority and bounded caching. Cancel obsolete preview requests and move changed-page analysis off the UI thread.
- Improve PDF-to-LaTeX navigation for included files and cached builds, checking source mappings against the displayed PDF.
- Fix document diagnostics and outlines across included files, including continuous slide numbering and navigation to the correct source.

## Writing and project controls

- Make Plan mode more visible and show questions in the composer, with clear answer selection and a separate submit action.
- Add consistent light/dark syntax highlighting and coloured labels for agent commands, research, file access and outcomes.
- Open project settings from the Data sources heading. Reference whole data sources and directories with `@` completion, with files listed directly.
- Clear submitted prompts promptly while retaining failed submissions and newer drafts.
- Consolidate project creation and file-exclusion policies, preserving writing sources and tracked assets while excluding build outputs.

## Windows installation

Run `codex-prism-1.7.1-windows-x86_64-setup.exe`, then open the app and use **Connection → Sign in**.

Setup reuses existing tools and installs missing Codex and MiKTeX through WinGet, plus WebView2 when needed. Internet access and Windows App Installer (WinGet) are required for those downloads. A newly installed MiKTeX is configured to download missing packages; existing distribution settings are preserved. Ghostscript's optional setup wizard enables optimized PDF export and may request administrator approval. Silent setup skips this optional wizard.

The Windows installer is unsigned. Prerequisites are separate installations and remain installed when codex-prism is removed.

## Ubuntu installation

Install `codex-prism-1.7.1-linux-x86_64.deb`:

```sh
sudo apt install ./codex-prism-1.7.1-linux-x86_64.deb
```

Or make the AppImage executable and run it:

```sh
chmod +x codex-prism-1.7.1-x86_64.AppImage
./codex-prism-1.7.1-x86_64.AppImage
```

These packages target Ubuntu 26.04; older distributions are not guaranteed to work. Install/authenticate Codex separately, and install TeX Live for compilation:

```sh
sudo apt install texlive-latex-extra texlive-publishers texlive-fonts-recommended texlive-xetex texlive-luatex texlive-bibtex-extra biber
```

## macOS installation

Open `codex-prism-1.7.1-macos-arm64.dmg` and copy codex-prism into Applications. Install/authenticate Codex separately and install MacTeX, for example:

```sh
brew install --cask mactex-no-gui
```

The app detects Codex bundled with ChatGPT or uses your configured executable. The macOS app is ad-hoc signed, **not Apple-notarized**. After a blocked initial launch, use **System Settings → Privacy & Security → Open Anyway** to approve it.

## Requirements and verification

Existing PDFs can be viewed without a LaTeX compiler. Python environments and scientific skills are optional. Node.js and Rust are not required to run the packaged application.

Optimized PDF export additionally requires Ghostscript (`sudo apt install ghostscript` on Ubuntu or `brew install ghostscript` on macOS). Verify downloads against `SHA256SUMS`; `release.json` records the source commit and package hashes. Automatic application updates are not enabled.
