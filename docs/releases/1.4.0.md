# codex-prism 1.4.0

Scientific writing with Codex, a LaTeX editor, and a PDF preview. This release targets **Ubuntu 26.04 LTS, x86_64**.

## Highlights

- Codex app-server integration using your installed Codex CLI and account, with project-scoped conversations, attachments, model and reasoning-effort selection, and resumable sessions.
- Compact change review with Keep/Undo. Starting another chat turn implicitly keeps pending changes once the new turn starts successfully.
- Chat remains visible when LaTeX code is hidden; Code is a one-click toggle beside Layout.
- Existing PDFs load before recompilation, with fit-width viewing by default and an optional Auto-recompile toggle.
- Clearer compiler diagnostics and corrected BibTeX invocation, preventing stale bibliographies and missing citations.
- Scientific-publication, verified-reference and TikZ guidance shared between the assistant and new project instructions.
- Simplified application: removed Zotero, unused provider code, updater remnants and embedded Tectonic. Python environments and external scientific skills are optional; opening a project does not create a virtual environment.

## Compiler change

Compilation now requires **system TeX Live**. The default engine is **pdfLaTeX**. For documents requiring another engine, add `% !TEX program = xelatex` or `% !TEX program = lualatex` within the main file's first 20 lines. TeX packages are no longer downloaded automatically.

On Ubuntu:

```sh
sudo apt install texlive-latex-extra texlive-publishers texlive-fonts-recommended texlive-xetex texlive-luatex texlive-bibtex-extra biber
```

Individual documents may need additional fonts or language packages. Existing PDFs can still be viewed without a compiler installed.

## Installation

Install the `.deb` with `sudo apt install ./codex-prism-1.4.0-linux-x86_64.deb`, or make the AppImage executable with `chmod +x codex-prism-1.4.0-linux-x86_64.AppImage` and run it. Both formats require TeX Live separately for compilation.

Install the Codex CLI separately and authenticate with `codex login`, or sign in through the app. The installed application does not require Node.js or Rust at runtime. Automatic updates and artifact signing are not enabled; verify downloads against `SHA256SUMS`.

## Existing projects

Documents, installed skills, Python environments and legacy `.claudeprism` snapshot history are preserved. Auto-recompile and Vim preferences are retained; the obsolete compiler-backend choice is removed. Existing project `AGENTS.md` files are not overwritten and may need their compiler instructions updated manually.

The `codex-prism` launcher in `~/.local/bin` continues to start the repository checkout. Rename or remove that launcher only if you want the packaged application to take precedence.
