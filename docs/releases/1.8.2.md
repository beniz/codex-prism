# codex-prism 1.8.2

## What's new

- **Collaborate on Git branches.** Click the branch name below the project title to switch branches. Each branch keeps its own chats and proposals. From Collaboration you can preview a remote branch or a GitHub or Gitea pull request, compile it for review, publish your branch, or merge changes into the active branch.
- **Complete LaTeX as you type.** The editor suggests standard, package and project commands, citation keys from your bibliography, and document labels inside `\ref{}` and `\eqref{}`.
- **Search the PDF preview.** With the PDF focused, press Ctrl+F or Ctrl+S (Cmd on macOS). Enter moves to the next match and Shift+Enter moves to the previous one. A wider divider with a visible grip makes the preview easier to resize.
- **Review shorter conflict-repair chats.** Full file contents stay in the repair workspace. Older repair prompts that embedded those contents appear as summaries in chat.
- **Reclaim disk space.** Prism cleans up cached proposal PDFs and build inputs after Keep or Discard, including older resolved proposals at startup.
- SSH data sources can discover Codex in common remote installation directories, including nvm. A new guide covers [migrating an OpenAI Prism project](https://github.com/beniz/codex-prism/blob/v1.8.2/docs/openai-prism-migration.md).

## Downloads

| Platform | Package |
| --- | --- |
| Ubuntu 26.04 x86_64 | `codex-prism-1.8.2-linux-x86_64.deb` or `codex-prism-1.8.2-x86_64.AppImage` |
| Windows 10/11 x64 | `codex-prism-1.8.2-windows-x86_64-setup.exe` |
| macOS Apple Silicon | `codex-prism-1.8.2-macos-arm64.dmg` |

Install the update manually. On Linux and macOS, install and authenticate Codex separately and install TeX Live or MacTeX to compile documents. Windows setup can supply missing prerequisites. The Windows installer is unsigned. The macOS app is ad-hoc signed and may require approval in System Settings → Privacy & Security.

Use `SHA256SUMS` to verify your download. `release.json` records the source commit and artifact hashes.
