# codex-prism 1.8.1

- Add file data sources while another chat works or awaits review. New chat workspaces pick up the saved files. Opaque PNG and BMP imports default to quality-90 JPEG copies for lighter PDFs. Turn off conversion to keep the original format.
- Keep preserves the reviewed PDF and scroll position when the accepted inputs match. When a merge needs a rebuild, the reviewed PDF stays visible while it compiles.
- Chat drafts remain editable while history loads. Background file operations and binary PDF transfers improve responsiveness during PDF preparation.
- Plan mode asks consequential questions in the composer. The model menu labels the automatic choice “Codex default”, and the activity indicator distinguishes starting a turn from connecting to Codex.
- New projects, including projects created from templates, prompt for a parent folder.

## Packages and installation

- **Ubuntu 26.04 x86_64:** `codex-prism-1.8.1-linux-x86_64.deb` or
  `codex-prism-1.8.1-x86_64.AppImage`. Older Linux distributions are not
  guaranteed to work. Install and authenticate Codex separately, and install
  TeX Live for compilation.
- **Windows 10/11 x64:** `codex-prism-1.8.1-windows-x86_64-setup.exe`.
  Setup reuses existing prerequisites and can install missing Codex, MiKTeX,
  and WebView2. The installer is unsigned.
- **macOS Apple Silicon:** `codex-prism-1.8.1-macos-arm64.dmg`. Copy the app
  into Applications; install/authenticate Codex and install MacTeX separately.
  The app is ad-hoc signed, not Apple-notarized. A blocked first launch can be
  approved through System Settings → Privacy & Security → Open Anyway.

Packages are installed manually. Python environments and scientific skills are
optional, and no Node.js or Rust installation is required to run the packaged
app. Existing PDFs can be viewed without a TeX compiler. Optimized PDF export
requires Ghostscript.

Verify downloads with `SHA256SUMS`. `release.json` records the source commit and
artifact hashes. The app checks for newer stable releases every 12 hours and links to manual
downloads. In-app installation and updater signing remain postponed.
