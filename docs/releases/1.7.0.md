# codex-prism 1.7.0

**Bring your research into every chat with project data sources.** Connect reference files, local folders, and remote directories to the document you are writing, then point agents to the material with `@` completion.

Desktop packages for **Ubuntu 26.04 LTS x86_64**, **Windows 10/11 x64**, and **macOS Apple Silicon**, built from the same v1.7.0 source tag.

## Data sources for every project

- Add reference files, local directories, and SSH connections when creating a project or later by clicking its title to open **Project settings → Data sources**.
- Reference files are copied into the project. Local directories remain in place and are made available to every project chat from its next turn. The sidebar shows availability, with a shared row for registered files.
- Connect remote Linux or macOS directories through SSH to an existing, authenticated Codex app-server. Remote research and computation run on that machine; document edits, compilation, and Git history remain local. Import selected remote files into the originating chat's proposal for review.
- Type `@` and press **Tab** to choose a registered source and browse its files, including remote directories. Completion is on demand, without indexing or model calls. Paths with spaces are quoted, and invalid references leave the prompt intact.
- Existing project attachments are registered automatically once. Source settings apply across chats from their next turn without interrupting current work.

SSH sources require an already running remote Codex server; Prism does not install or start it. If needed, establish the remote connection through **ChatGPT Settings → Connections** first, then enter the SSH alias in Prism. Remote agents are instructed not to modify sources; this is **instruction-based protection, not enforced filesystem read-only access**. Local directory sources are exposed read-only. See the [data-source reference](https://github.com/beniz/codex-prism/blob/v1.7.0/README_AGENTS.md#project-data-sources) for setup and limits.

## Faster compilation and other improvements

- Add a persistent **Incremental** toggle next to Auto and Changes, enabled by default. Turn it off to request full compilation.
- Skip redundant LaTeX passes only when recorded dependencies and stable auxiliary state prove they are unnecessary. Skip unchanged BibTeX/Biber processing only when controls, bibliography inputs, tool identity, and output are verified. Uncertain cases retain the full compilation sequence.
- Return completed chats with no pending edits to the latest main-document PDF, including recovery after restart. Chats with pending changes retain their own previews.
- Move Capture & Ask to **Ctrl+Shift+X** (**Cmd+Shift+X** on macOS), restoring normal cut behavior in text fields.

## Windows installation

Run `codex-prism-1.7.0-windows-x86_64-setup.exe`, then open the app and use **Connection → Sign in**.

Setup reuses existing tools and installs missing Codex and MiKTeX through WinGet, plus WebView2 when needed. Internet access and Windows App Installer (WinGet) are required for those downloads. A newly installed MiKTeX is configured to download missing packages; existing distribution settings are preserved. Ghostscript's optional setup wizard enables optimized PDF export and may request administrator approval. Silent setup skips this optional wizard.

The Windows installer is unsigned. Prerequisites are separate installations and remain installed when codex-prism is removed.

## Ubuntu installation

Install `codex-prism-1.7.0-linux-x86_64.deb`:

```sh
sudo apt install ./codex-prism-1.7.0-linux-x86_64.deb
```

Or make the AppImage executable and run it:

```sh
chmod +x codex-prism-1.7.0-x86_64.AppImage
./codex-prism-1.7.0-x86_64.AppImage
```

These packages target Ubuntu 26.04; older distributions are not guaranteed to work. Install/authenticate Codex separately, and install TeX Live for compilation:

```sh
sudo apt install texlive-latex-extra texlive-publishers texlive-fonts-recommended texlive-xetex texlive-luatex texlive-bibtex-extra biber
```

## macOS installation

Open `codex-prism-1.7.0-macos-arm64.dmg` and copy codex-prism into Applications. Install/authenticate Codex separately and install MacTeX, for example:

```sh
brew install --cask mactex-no-gui
```

The app detects Codex bundled with ChatGPT or uses your configured executable. The macOS app is ad-hoc signed, **not Apple-notarized**. After a blocked initial launch, use **System Settings → Privacy & Security → Open Anyway** to approve it.

## Requirements and verification

Existing PDFs can be viewed without a LaTeX compiler. Python environments and scientific skills are optional. Node.js and Rust are not required to run the packaged application.

Optimized PDF export additionally requires Ghostscript (`sudo apt install ghostscript` on Ubuntu or `brew install ghostscript` on macOS). Verify downloads against `SHA256SUMS`; `release.json` records the source commit and package hashes. Automatic application updates are not enabled.
