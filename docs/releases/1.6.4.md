# codex-prism 1.6.4

Desktop packages for **Ubuntu 26.04 LTS x86_64**, **Windows 10/11 x64**, and **macOS Apple Silicon**, built from the same v1.6.4 source tag.

## Changes

- Add High quality (300 dpi) PDF export as the default, alongside Compact (150 dpi) and Original. High quality uses lossless image encoding after downsampling to preserve figure detail without JPEG artifacts. Optimized exports require Ghostscript and retain the original bytes if optimization does not reduce size.
- List Beamer slides in the outline, including frame titles, untitled slides, and navigation to source and PDF. Custom commands that generate frames are not expanded.
- Automatically reveal the LaTeX source panel when opening a file from the Files navigator.
- Navigate newly compiled agent PDFs to the first page mapped to modified source instead of resetting to the front page. Retain the current page when changed content has no source mapping.
- Mark chat tabs with an amber dot when their changes await review, making pending proposals easier to find across concurrent chats.
- Refresh project documentation and changelog, add contributor guidance for coding agents, and remove obsolete translated README stubs and Gitea release tooling. Releases continue through GitHub Actions.

## Windows installation

Run `codex-prism-1.6.4-windows-x86_64-setup.exe`, then open the app and use **Connection → Sign in**.

Setup reuses existing tools and installs missing Codex and MiKTeX through WinGet, plus WebView2 when needed. Internet access and Windows App Installer (WinGet) are required for those downloads. A newly installed MiKTeX is configured to download missing packages; existing distribution settings are preserved. Ghostscript's optional setup wizard enables optimized PDF export and may request administrator approval. Silent setup skips this optional wizard.

The Windows installer is unsigned. Prerequisites are separate installations and remain installed when codex-prism is removed.

## Ubuntu installation

Install `codex-prism-1.6.4-linux-x86_64.deb`:

```sh
sudo apt install ./codex-prism-1.6.4-linux-x86_64.deb
```

Or make the AppImage executable and run it:

```sh
chmod +x codex-prism-1.6.4-x86_64.AppImage
./codex-prism-1.6.4-x86_64.AppImage
```

These packages target Ubuntu 26.04; older distributions are not guaranteed to work. Install/authenticate Codex separately, and install TeX Live for compilation:

```sh
sudo apt install texlive-latex-extra texlive-publishers texlive-fonts-recommended texlive-xetex texlive-luatex texlive-bibtex-extra biber
```

## macOS installation

Open `codex-prism-1.6.4-macos-arm64.dmg` and copy codex-prism into Applications. Install/authenticate Codex separately and install MacTeX, for example:

```sh
brew install --cask mactex-no-gui
```

The app detects Codex bundled with ChatGPT or uses your configured executable. The macOS app is ad-hoc signed, **not Apple-notarized**. After a blocked initial launch, use **System Settings → Privacy & Security → Open Anyway** to approve it.

## Requirements and verification

Existing PDFs can be viewed without a LaTeX compiler. Python environments and scientific skills are optional. Node.js and Rust are not required to run the packaged application.

Optimized PDF export additionally requires Ghostscript (`sudo apt install ghostscript` on Ubuntu or `brew install ghostscript` on macOS). Verify downloads against `SHA256SUMS`; `release.json` records the source commit and package hashes. Automatic application updates are not enabled.
